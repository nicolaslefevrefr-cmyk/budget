# Budget Scénarios
PWA de budget mensuel avec scénarios (dupliquer, renommer, comparer), valeurs fixes / ± % / plages (sous-scénarios optimiste, central, pessimiste), import/export JSON (nom du projet + date). Données enregistrées localement (stockage persistant demandé).
Déploiement GitHub Pages : poussez le contenu de ce dossier à la racine d'un repo, puis Settings → Pages → branche `main` / racine.
